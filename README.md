# Tractive-System-and-Telemetry-Analysis
Formula Student technical exercise featuring a C++ tractive-system state-machine simulation and MATLAB analysis of vehicle telemetry, suspension behaviour and energy consumption.
Scope and Limitations

These are separate software and data-analysis tasks, not an integrated vehicle control system. Wheel-spin events are candidate detections, and the suspension anomaly requires calibration and mechanical checks before its cause can be confirmed.

The work was completed as a technical selection exercise and does not imply membership of, or employment by, the team.
